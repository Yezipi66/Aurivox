============================================================
  TTS Broker — 使用说明(最终用户)
============================================================

【环境要求】
  * Windows 10 / 11 (64 位)
  * NVIDIA 显卡 + 已安装 NVIDIA 驱动(支持 CUDA 12.1),显存建议 ≥ 8GB
  * 首次部署需联网(下载 PyTorch 与模型,约 10GB 流量)
  * 无需自行安装 Python 或 Node —— 已内置

------------------------------------------------------------
【第一步:首次部署】双击  首次部署.bat
------------------------------------------------------------
  它会自动:
    1) 用内置 Python 3.11 创建虚拟环境 venv\
    2) 安装依赖(离线轮子 + 联网 PyPI,不含 torch)
    3) 安装 PyTorch (CUDA 12.1)
    4) 弹出"模型下载向导",引导你下载模型(约 9GB)
       - 选 1 下载全部;若在国内,菜单里可切换 hf-mirror 镜像加速
    5) 自检
  * 全程耐心等待,首次可能 20~60 分钟(取决于网速)。
  * 若中途失败,重跑本脚本即可(支持续跑,已装的会跳过)。

------------------------------------------------------------
【第二步:启动】双击  启动.bat
------------------------------------------------------------
  * 浏览器会自动打开  http://127.0.0.1:9886
  * 后端与推理引擎在后台运行,关闭黑窗口不影响它们。
  * 日志在 logs\ 下(startup / backend / inference)。

------------------------------------------------------------
【停止】双击  停止.bat
------------------------------------------------------------

------------------------------------------------------------
【常见问题】
------------------------------------------------------------
  Q: 启动.bat 提示未检测到 venv?
     A: 先运行 首次部署.bat。

  Q: 模型没下全 / 想补下?
     A: 命令行运行:
        venv\Scripts\python.exe tools\deploy\download_models.py --wizard
        或先体检:  venv\Scripts\python.exe tools\deploy\download_models.py --check

  Q: torch.cuda.is_available() = False?
     A: 说明显卡驱动/CUDA 不匹配。请更新 NVIDIA 驱动到支持 CUDA 12.1 的版本。

  Q: 端口被占用?
     A: 后端 9886 / 引擎 9880。先运行 停止.bat 再启动。

  Q: 需要 ffmpeg 吗?
     A: 大多数流程不需要。仅"人声分离 / UVR5 去背景音"依赖 ffmpeg,
        且它不随包分发(约 275MB)。需要时命令行运行:
        venv\Scripts\python.exe tools\deploy\download_ffmpeg.py
        (会自动下载到 vendor\ffmpeg\ 下;--check 只检查, --force 重下)
        提示: 若你的素材本身就是干净人声,通常无需人声分离,也就无需 ffmpeg。
