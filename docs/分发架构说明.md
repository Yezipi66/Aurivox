# 分发架构说明

## 分发模型
GitHub Release 只放**一个「解压即用」的源码包**(Windows x64)。
模型完全隔离,由用户跑向导自行下载。

```
解压后的项目根/  ← 保持极简: 只有 3 个入口 .bat + README + 业务源码
├─ 首次部署.bat            ← 用户第一步:建 venv + 装依赖 + 装torch + 引导下模型
├─ 启动.bat / 停止.bat     ← 日常启停(薄封装,转调 tools\scripts)
├─ README_用户版.txt
├─ server.js  lib\  web\dist\  node_modules\(prod)  *.json 业务配置
├─ requirements.txt        ← 已注释掉 torch/torchvision(单独装)
└─ tools\                  ← 所有脚本/工具/运行时都在这里, 不污染根目录
   ├─ runtime\python\      ← 内嵌 CPython 3.11(建 venv 用)
   ├─ runtime\node\        ← 便携 Node(跑 server.js)
   ├─ wheels\              ← jieba_fast / pyopenjtalk 预编译轮子
   ├─ deploy\              ← 部署/运维脚本:
   │   ├─ bootstrap.ps1        部署主逻辑(建venv→装依赖→调install_torch→自检→下模型)
   │   ├─ install_torch.ps1 / 安装PyTorch.bat   单独装 torch(可重复运行)
   │   ├─ download_models.py   模型下载/体检向导(不含模型本体)
   │   └─ download_ffmpeg.py   ffmpeg 二进制(可选, 仅人声分离需要)
   ├─ scripts\            ← 启停 + 开发者工具:
   │   ├─ start.ps1 stop.ps1
   │   ├─ dump_tree.ps1        导出目录结构(开发者)
   │   └─ 清理根目录.bat        清理历史残留(开发者)
   └─ build\ 00~04         ← 开发者打包用(用户用不到)
```
注: vendor\ffmpeg\ 不随包分发(约 275MB, 可选), 需要时由 download_ffmpeg.py 下载。

## 三大依赖缺口的解法
| 缺口 | 解法 |
|---|---|
| 用户没 Node | 内嵌便携 node,`server.js` 用它跑;前端预 build 成 `web\dist` |
| 用户没 Python / 没编译器 | 内嵌可重定位 Python 3.11;需编译的包预编译成轮子放 `tools\wheels` |
| torch 太大 + 认 CUDA | 部署脚本单独从 `download.pytorch.org/whl/cu121` 装 torch 2.2.0 |

## 运行期端口 / 进程
- 后端 `server.js` : 127.0.0.1:**9886**(UI 也在这)
- 推理引擎 `infer_server.py` : 127.0.0.1:**9880**
- venv 布局沿用 `venv\Scripts\python.exe`(start.ps1 依赖此路径)

## 模型下载矩阵(download_models.py)
| 组 | 内容 | 目标目录 | 来源(默认) |
|---|---|---|---|
| core | gsv/v2Pro/sv/hubert/roberta/bigvgan | `lib\training\gsv-tools\pretrained\` | lj1995/GPT-SoVITS + nvidia/bigvgan |
| asr | faster-whisper-large-v3 | `...\asr\models\faster-whisper-large-v3\` | Systran/faster-whisper-large-v3 |
| uvr5 | HP2_all_vocals | `...\uvr5\uvr5_weights\` | lj1995/GPT-SoVITS |
| g2pw | g2pW.onnx(写两份副本) | `GPT_SoVITS\text\G2PWModel\` + gsv_code 副本 | HF 直链(需确认) |
| langdetect | lid.176.bin(写两份副本) | `...\pretrained\fast_langdetect\` + gsv_code 副本 | fasttext 官方直链 |

> ⚠ `g2pw` 的 onnx 直链是占位,发布前请用 `--check` 验证是否可下;
> 若你当初的实际来源不同(如 ModelScope/镜像),改 `download_models.py` 顶部的
> `URL_G2PW_ONNX / HF_REPO_*` 即可。

## 已知重复文件(下载器已自动同步两份)
- `g2pW.onnx`:`GPT_SoVITS\text\G2PWModel\` 与 `lib\training\gsv_code\text\G2PWModel\`
- `lid.176.bin`:`gsv-tools\pretrained\fast_langdetect\` 与 `gsv_code\pretrained_models\fast_langdetect\`
