# 文案语气规范（本轮统一口径）

> 适用：**用户可见文案**（`t('en','中文')` 中文位、JSX 可见文本、`zh:`/`error:`/`note:`/`why:`/`hint:`/`label:`/`title:`/`caveat:`/`message:`、后端返回给前端的消息、CLI 打印）。
> ⛔ 不适用：代码注释、测试、变量名。

## 两条总原则

1. **正式、严谨、规范** —— 用户看到的每一句都应是软件该说的话，不是人在聊天。
2. **规范严谨优先于简短** —— 短标签（徽章/按钮）也可以写全，不要为省字牺牲规范。

## ⛔ 符号：全部保留，只改文字

`⛔` / `⭐` / `✅` / `⚠` / `★` 一律**保留原位**（它们是产品符号）。
本轮**只改符号后面的文字**，不许删符号、不许改符号。

## 替换对照表（按类）

### 一、口语动词 → 书面语

| 口语 | 规范 |
|---|---|
| 在跑 / 正在跑 | 运行中 / 正在运行 |
| 没在跑 | 未在运行 |
| 起来了 / 起起来 | 已启动 / 启动 |
| 没起来 | 启动失败 |
| 起不了也停不了 | 无法启动或停止 |
| 开跑 | 开始运行 |
| 跑完 | 执行完成 |
| 跑一遍 / 重新跑一遍 | 执行一次 / 重新执行 |
| 跑切片 | 运行切片 |
| 试跑 | 试运行 |
| 干活 | 执行任务 |
| 搞定 | 完成 |
| 读不了 / 读不出来 / 读不到 | 无法读取 |
| 存不进 | 无法写入 |
| 拉回来 | 加载 |
| 画不出 | 无法显示 |
| 补上 | 补充 |
| 载不进来 | 无法加载 |
| 用不到 / 用到才起 | 按需启动 |

### 二、含糊副词 → 删掉或说具体

| 口语 | 规范 |
|---|---|
| 多半是 X | 通常为 X / 可能由 X 导致（能说具体就说具体） |
| 大概 | 预计 |
| 最可能是 | 通常是 |
| 其实 | （删） |
| 反正 | （删） |

| 口语 | 规范 |
|---|---|
| 没活着回来 | 未成功启动 |
| 被赶出来了 | 被系统终止 |
| 吃多少内存 / 吃到 | 内存占用量 / 占用 |
| 爆显存 | 耗尽显存 |
| 显存吃紧 / 显存富裕 | 显存不足 / 显存充足 |
| 更吃显存 | 显存占用更大 |
| 没装看管人 | 未安装进程管理器 |
| 半截音频 | 不完整的音频 |
| 发糊 / 发闷 | 模糊 / 沉闷 |
| 听着干净 | 音质清晰 |
| 身上没有配方 | 未附带配方 |
| 对不上号 | 数量不匹配 |
| 攒 | 累计 |
| 一只 / 几只 / 一堆 | 台 / 若干台 / 多个 |

### 四、短标签（徽章 / 按钮）

| 口语 | 规范 |
|---|---|
| 底模齐 | 底模就绪 |
| 底模没放 | 底模缺失 |
| 没量到 / 没量过 | 未测量 |
| 已存 | 已保存 |
| 知道了 | 已知晓 |
| 好了 | 操作完成 |
| 用到才起 | 按需启动 |

### 五、程度 / 评价词 → 客观表述

| 口语 | 规范 |
|---|---|
| 最干净 | 最佳 |
| 最稳 | 最稳定 |
| 更干净 | 效果更佳 |
| 要多等一会儿 | 需要更长时间 |
| 随便填 | 可填写任意值 |
| 从库里挑一个 | 从列表中选择一项 |
| 这一块 | 此区域 |
| 这一下 | 此过程 |
| 那张 / 这几台 | 该 / 这些 |
| 想省磁盘 | 希望节省磁盘空间 |
| 跟着…走 | 取决于 |
| 不会点亮 | 不会高亮显示 |
| 边合边回 | 边合成边返回 |
| 钉语言 | 固定语言 |
| 免重抽 | 免重新提取 |
| 保持热 | 保持缓存 |
| 看着像网络故障 | 表现为网络故障 |
| 要先去主页点同意才能下 | 需先在模型主页接受许可 |
| 拿什么合成 | 使用什么文本合成 |

### 六、第二人称「你」 → 无主句 / 该对象

| 口语 | 规范 |
|---|---|
| 你 | （删）或「使用者」 |
| 平台不替你挑 | 平台不代为选择 |

### 七、内部设计原则 → 删（用户不需要知道）

| 口语 | 规范 |
|---|---|
| 这正是这个页面存在的理由 | （删整句） |
| 平台不替你猜 / 契约里明确允许 / 这不是错 | （删或改陈述事实） |

### 八、标点

| 不规范 | 规范 |
|---|---|
| 中文文案里的 `——` | 冒号 `：` 或逗号 `，` |
| 中文文案里的单个 `—` | 冒号 `：` 或逗号 `，` |
| 英文文案里的 `—` | **保留**（英文 em dash 正确） |
| 非规范箭头 `->` | 中文文案里改「→」或写「转为」 |

## 改法自检（每条改完问自己）

1. 这句话像一个软件说的，还是像人在聊天？
2. 把这句话给一个不认识这个项目的人看，他能准确理解吗？
3. 有没有把我们的内部设计原则讲给用户听？
4. 符号（⛔/⭐/✅/⚠/★）还在原位吗？
