# 打包发布指南(开发者侧)

在**你自己的 Windows 开发机**(已装 VS2026 Build Tools + C++ 工作负载 + CMake)上,
把项目做成一个「解压即用」的 GitHub Release zip。

## 一键流程

```bat
tools\build\00_build_all.bat --version 1.0.0
```

它依次执行 03 → 01 → 02 → 04。也可以分步单独跑:

| 步骤 | 脚本 | 作用 |
|---|---|---|
| 03 | `tools\build\03_fetch_runtimes.py` | 下载内嵌 **Python 3.11** + **便携 Node** 到 `tools\runtime\` |
| 01 | `tools\build\01_build_frontend.bat` | 用内嵌 node 装**根后端依赖**(prod)+ 构建 **`web\dist`** |
| 02 | `tools\build\02_make_wheelhouse.bat` | 用 VC 环境编译 **jieba_fast / pyopenjtalk** 轮子 → `tools\wheels\` |
| 04 | `tools\build\04_pack_release.py` | 组装 **release zip** 到 `dist\`(排除模型/venv/私人资产) |

## 各步骤要点

### 03 内嵌运行时
- 版本在脚本顶部 `PY_VER / NODE_VER` 处 pin,想升级改这里。
- Python 用 **python-build-standalone**(可重定位、支持 venv/pip/编译扩展),
  不是官方 embeddable(那个跑不了 torch)。

### 02 造轮子(需你机器的编译环境)
- 自动定位 `C:\Program Files (x86)\Microsoft Visual Studio\18\BuildTools\...\vcvars64.bat`,
  找不到会用 `vswhere` 兜底。
- **pyopenjtalk 需要 CMake**,jieba_fast 需要 MSVC。确保 VS 里勾了
  「使用 C++ 的桌面开发」+ CMake 组件。
- 轮子必须用**内嵌的 Python 3.11** 构建(脚本已优先选它),保证 cp311 ABI 与用户端一致。

### 04 打包(排除清单)
自动**排除**:所有模型(`.pth/.ckpt/.pt/.onnx/.bin/.safetensors`)、模型目录
(`pretrained/ asr/ uvr5_weights/`)、`venv/`、`assets/`(你训练的角色)、
`voices/ data/ logs/ outputs/ backups/ .git/ .staging/`、`web/node_modules/`。
**保留**:源码、`web\dist`、根 `node_modules`、`vendor\ffmpeg`、`tools\`(含 runtime+wheels)。
- 打包前会打印 >100MB 的大文件清单(应只有 ffmpeg / node / python),便于核对。
- 缺 dist / runtime / wheels 会给 `[WARN]`。

## 发布前自检清单
- [ ] `tools\runtime\python\python.exe`、`tools\runtime\node\node.exe` 存在
- [ ] `web\dist\index.html` 存在
- [ ] `tools\wheels\*.whl` 至少有 jieba_fast、pyopenjtalk
- [ ] 根 `node_modules\express` 存在
- [ ] `dist\TTS-Broker-*.zip` 里**不含**任何模型或 `assets/`

把 `dist\TTS-Broker-<ver>-win-x64-*.zip` 传到 GitHub Release 即可。
```
python tools\build\04_pack_release.py --version 1.0.0 --dry-run   # 先预览不写盘
```
