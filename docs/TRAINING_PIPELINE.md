# TTS Training Pipeline 设计文档

## 产品设计哲学

### 核心理念：一键训练，零门槛

> 用户只需要做两件事：放入音频 + 选择语言。剩下的全部自动完成。

我们面向的不是算法工程师，是内容创作者。他们关心的是"我想让这个角色说出台词"，而不是"我的切片阈值应该是多少"。

### 用户看到的界面

```
┌─────────────────────────────────────────────────────────┐
│  🎙️ 训练新语音                                          │
│                                                         │
│  音频文件夹:  [ /path/to/raw/audio/ ]  [ 浏览... ]      │
│                                                         │
│  语言:  [ 日语 ▼ ]                                      │
│                                                         │
│  预处理选项:                                            │
│  ☐ 去人声（原始音频有噪音时开启）                        │
│  ☐ 语音切片（原始音频较长时开启）                        │
│  ☐ 语音识别（自动生成参考文本）                          │
│                                                         │
│  ┌─────────────────────────────────────────────────┐    │
│  │  ● 去人声  →  ● 语音切片  →  ● 语音识别  →  ● 训练 │    │
│  └─────────────────────────────────────────────────┘    │
│                                                         │
│              [ 🚀 开始训练 ]                             │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 设计原则

1. **用户必须选两件事**：音频文件夹 + 语言
2. **预处理选项由用户根据音频情况勾选**：不是所有步骤都是必须的
3. **过程全自动**：用户点开始后不需要干预
4. **进度可见**：用户能看到当前在哪个步骤、进度如何
5. **结果直接可用**：训练完成自动注册到 assets/，Generate 页面立即可用
6. **不暴露引擎细节**：用户不需要知道 GPT-SoVITS、UVR5、Whisper 这些词
7. **默认参数外置**：训练参数存储在 `training_defaults.json`，不硬编码
8. **高级设置预留**：后续实现，当前不做

### 预处理选项说明

| 步骤 | 默认状态 | 说明 |
|------|---------|------|
| 去人声 | 关闭 | 原始音频有背景音乐/噪音时开启 |
| 语音切片 | 关闭 | 原始音频较长（>1分钟）时开启 |
| 语音识别 | 关闭 | 需要自动生成参考文本时开启 |

**注意：** 如果用户已有音频+文本对（比如之前已经做过 ASR），可以跳过所有预处理直接训练。
如果用户只有音频没有文本，必须开启"语音识别"，否则训练出的模型无法做文本到语音的合成。

### 不做的事情

- ❌ 不要求用户准备文本文件（ASR 自动生成）
- ❌ 不要求用户理解模型架构
- ❌ 不要求用户手动对齐音频和文本
- ❌ 不暴露参数（后续高级设置再做）
- ❌ 不做成"工具箱"（那是 GPT-SoVITS 做的事）
- ❌ 不做文本校对（后续版本再做）

## 用户操作流程

### 主流程（唯一）

```
1. 用户选择音频文件夹（包含原始音频文件）
2. 用户选择语言（ja/zh/en/ko 等）
3. 用户点击"开始训练"
4. 系统自动执行全部步骤：
   ┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐
   │ 去人声   │ → │ 语音切片 │ → │ 语音识别 │ → │ 训练     │
   │ (默认开启)│   │ (默认开启)│   │ (默认开启)│   │ (自动)   │
   └──────────┘   └──────────┘   └──────────┘   └──────────┘
5. 训练完成，自动注册到 assets/{voiceId}/
6. 用户可直接在 Generate 页面使用新训练的模型
```

### 高级设置（后续实现，当前不做）

```
- 去人声开关、模型选择
- 切片参数（最小长度、静音阈值）
- ASR 模型选择
- 训练参数（轮数、batch size、学习率）
```

## Pipeline 步骤详解（内部实现，用户不可见）

### Step 1: 去人声 (Vocal Separation)

**目的**：从原始音频中提取纯人声，去除背景音乐、环境噪音
**输入**：原始音频文件（长音频）
**输出**：纯人声音频文件
**默认参数**：模型 MDX-Net，阈值 0.5
**依赖**：tools/uvr5/ 中的 bs_roformer + mdxnet

### Step 2: 语音切片 (Audio Slicing)

**目的**：将长音频按静音切分成短片段（每段 3-15 秒）
**输入**：纯人声音频（可能很长）
**输出**：N 段短音频（slicer_opt/ 目录）
**默认参数**：最小 3s，最大 15s，静音阈值 -40dB，最小静音 0.5s
**依赖**：tools/slicer2.py

### Step 3: 语音识别 (ASR)

**目的**：将音频片段识别为文本，生成参考文本
**输入**：每段短音频
**输出**：每段音频对应的文本
**默认参数**：模型 faster-whisper large-v3，语言由用户指定
**依赖**：tools/asr/ 中的 fasterwhisper_asr.py

### Step 4: 预处理 (Preprocessing)

**目的**：为训练准备所有中间数据
**输入**：音频文件 + 对应文本
**输出**：segments.json、meta.json、BERT 特征等
**依赖**：GPT_SoVITS/ 中的 preprocess 逻辑

### Step 5: 训练 (Training)

**目的**：训练 GPT 和 SoVITS 模型
**输入**：预处理后的数据
**输出**：模型权重文件（ckpt、pth）
**默认参数**：GPT 20 轮，SoVITS 20 轮，batch size 自动
**依赖**：GPT_SoVITS/s1_train.py + s2_train.py

## 技术实现方案

### 后端架构

```
api.py / server.js
    │
    ├── POST /api/train/start          → 启动训练 pipeline
    ├── GET  /api/train/status/{id}    → 查询训练状态
    ├── POST /api/train/cancel/{id}    → 取消训练
    ├── GET  /api/train/logs/{id}      → 获取训练日志
    │
    └── lib/training/pipeline.js       → Pipeline 编排器
            │
            ├── step1_denoise.js       → 调用 UVR5
            ├── step2_slice.js         → 调用 Slicer
            ├── step3_asr.js           → 调用 Whisper
            ├── step4_preprocess.js    → 特征提取
            └── step5_train.js         → s1 + s2 训练
```

### 数据流

```
原始音频 (用户上传)
    │
    ▼
[去人声] ──→ 纯人声音频
    │
    ▼
[切片] ──→ N 段短音频 (assets/{id}/slicer_opt/)
    │
    ▼
[ASR] ──→ 每段音频的文本 (assets/{id}/segments.json)
    │
    ▼
[预处理] ──→ 训练数据 (assets/{id}/meta.json)
    │
    ▼
[训练] ──→ 模型权重 (assets/{id}/gpt_checkpoints/, assets/{id}/sovits_models/)
    │
    ▼
[注册] ──→ voices.json 更新 → Generate 页面可用
```

## 实现计划

### Phase 1: 后端 API（MVP）

1. 创建 `lib/training/` 目录
2. 实现 Pipeline 编排器
3. 封装去人声 API
4. 封装切片 API
5. 封装 ASR API
6. 封装预处理 API
7. 封装训练 API
8. 实现状态查询 API

### Phase 2: 前端 Pipeline UI

1. 训练页面入口（导航栏新增"Train"按钮）
2. 音频上传 + 语言选择
3. 步骤配置（勾选开关）
4. Pipeline 进度可视化
5. 日志实时展示

### Phase 3: 文本校对

1. 音频播放器 + 文本编辑框
2. 保存校对结果
3. 跳过校对直接用 ASR 输出

### Phase 4: 高级设置

1. 每个步骤的参数展开面板
2. 保存用户参数
3. 参数预设管理
